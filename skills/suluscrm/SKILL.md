---
name: suluscrm
description: Use the connected SulusCRM tools to look up and update contacts, conversations, appointments, invoices and other CRM records in the user's chosen Location. Use when the user asks about their CRM, customers, leads or schedule.
---

1. Use the SulusCRM server's tools. They cover one Location, chosen when the user signed in, and only the actions that user's role allows.
2. Search before creating, so you do not add a duplicate contact.
3. Before sending a message, charging a customer, or deleting a record, tell the user what will happen and wait for a yes.
4. If a tool is missing or refused, the user's role may not allow it. Say so plainly instead of trying another route.
5. To use a different Location, ask the user to remove and reconnect the SulusCRM server and pick it at sign-in.
