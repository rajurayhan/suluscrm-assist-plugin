# SulusCRM for SulusAssist

Connects SulusAssist to one SulusCRM Location through the hosted MCP server at
`https://crm.sulus.ai/suluscrm-mcp/connect`.

- **Sign in:** choose **Sign in** on the installed server, log in to SulusCRM, then pick the Location to use
  (skipped if you only have one). Tools match your role in that Location.
- **One Location per connection.** To use another, reconnect and pick it.
- No credentials are stored in this repository.
